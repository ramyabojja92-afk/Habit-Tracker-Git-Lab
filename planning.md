# Habit Tracker - Planning

## Product Idea
We will build a simple habit tracker app where users can add habits, view their habit list, mark habits as completed, and delete habits. The app will also have a simple menu for navigation.

## User Stories

1. As a user, I want to use a menu so that I can navigate easily.
2. As a user, I want to add a habit so that I can track it.
3. As a user, I want to view my habits so that I can see what I need to do.
4. As a user, I want to mark a habit as done so that I can track my progress.
5. As a user, I want to delete a habit so that I can remove habits I no longer need.

## Prioritized Backlog

1. Create menu/navigation
2. Add habit
3. View habits
4. Mark habit as done
5. Delete habit

## Git and Collaboration Plan

- Work in the same repository.
- Use branches for all changes.
- Make small commits regularly.
- Merge changes into main using pull requests.
- Work with mob programming during parts of the project.
- Rotate driver and navigator roles.
- Create one merge conflict intentionally.
- Resolve the merge conflict together.
