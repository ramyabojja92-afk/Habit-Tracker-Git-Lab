# Product Idea
Simple habit tracker app

# User Stories
1. As a user, I want to add a habit so that I can track it
2. As a user, I want to view habits so that I can see what to do
3. As a user, I want to mark a habit as done so that I track progress
4. As a user, I want to delete a habit so that I can remove it
5. As a user, I want a menu so that I can navigate easily

# Backlog
